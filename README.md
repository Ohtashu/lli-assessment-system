# LLI Assessment System

Full-Stack IT Asset & Inventory Management System built from the ground up using ReactJS, Ant Design, ExpressJS, and MSSQL for the LLI technical assessment.

## Structure

```
lli-assessment-system/
├── backend/             # ExpressJS API with MSSQL connection pool
├── frontend/            # ReactJS + Ant Design UI
└── database/            # MSSQL schema and seed data
```

See each subfolder README for setup and run instructions.
